Once per device

The phone keeps a token afterwards and never asks again. If it asks again, something removed that token — reinstalling the app does, because it wipes the app's data.

The token is never stored here

Only a SHA-256 of it, plus the first eight characters so the device is identifiable in the list above. A copied database yields no working credential.

Revoked, never deleted

A lost phone is revoked from the desktop. The row stays, because what that device was carrying is a fact worth keeping.

Nothing leaves the network

The phone talks to this machine and nothing else. No cloud, no account, and the app cannot file or send anything to a tribunal.
