{% endblock %} {% block inspector_title %}What counts as proof{% endblock %} {% block inspector %}

A document in the record

Something another person can open and read. It needs a locator — a page or paragraph — because "it is in the record somewhere" cannot be handed to a tribunal. Documentary proof is refused here without one.

Something you recall

Worth recording, and not proof of the fact. It is a record that you recall it, made on a date. It never raises an event above UNKNOWN, and the timeline always shows how long after the event it was written down.

Why the gap is shown

A memory written down the same week is a different thing from the same memory written down two years later. The gap is arithmetic on two dates, so it is reported. It is not scored, and it does not mean the account is wrong.

Attaching proof does not verify

Documentary proof moves an event to PARTIALLY_VERIFIED and no further. Someone still has to open the document and confirm it says what the event claims. VERIFIED_PRIMARY is a decision a person makes.

Nothing is deleted

Proof cannot be removed, only superseded. A proof row that quietly vanished would leave an event looking better supported than its history shows.

Filing and order dates

These are read off the document itself — the signature block, the dated line, the service date — and every one carries the cue it came from. You do not need to enter them by hand.
