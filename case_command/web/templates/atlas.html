Plain English

Preservation

Raising an issue, asking for a ruling on it, and getting one — so a reviewing court can consider it later. An issue never raised is usually not reviewable.

Exceptions

Written objections to a Recommended Decision. Missing the window can forfeit the objection even when the point was good.

Waiver

Losing a right by not asserting it in time. An unruled motion left alone on the record is the common way this happens.

Why "blocked" and not "unlikely"

A path here is blocked when a named record fact is missing, and the missing thing is stated so it can be fixed. This system does not estimate how likely a filing is to succeed.
