Open

This system found no recorded obstacle. That is a statement about the record, not advice that the path is available in law.

Blocked

A named record fact is missing, and the map states which one, so it can be fixed. Blocked never means unlikely — nothing here estimates whether a filing would succeed.

Missing from record

The amber node is the prerequisite itself. Supply it and the path it gates stops being blocked.

Preserves

Taking the step keeps an issue reviewable on appeal. An issue never raised is usually not reviewable at all.

Exceptions

Written objections to a Recommended Decision. Missing the window can forfeit the objection even when the point was good.

Waiver

Losing a right by not asserting it in time. An unruled motion left alone on the record is the common way this happens.

Why there is no score

Every number on this page is a count with a denominator, so it can be checked against the record. A single health percentage could not be.
